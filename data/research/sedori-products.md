# 日本と海外のせどり：ちょうど良い商材の調査

- 調査日: 2026-10-30
- 前提: 初期予算10万円（うち古物商の許可の手数料19,000円）。方針は「海外の顧客から外貨を稼ぐ」（[prompts/ceo.md](../../prompts/ceo.md)）。前回の物販の候補は [budget-100k-business-ideas.md](budget-100k-business-ideas.md) §3
- 「ちょうど良い」の定義: 予算10万円で**数点〜十数点を回せる単価**で、**一人で検品・梱包・発送ができ**、**真贋や規制のリスクが小さく**、**海外と国内の価格差を自分で調べられる**商材
- 表記: **【事実】** 出典で確認済み / **【推測】** 分析・仮説 / **【未確認】** 裏付けなし
- **調査方法の制約**: Web検索の要約によるもの。eBayの落札済み価格（Sold）や国内の仕入れ値を、商品ごとに実際に照合してはいない。**利益率はどの商材も【未確認】**で、§6の手順で人間が実測する必要がある

## 1. 方向の比較：輸出か輸入か

| | 日本→海外（輸出） | 海外→日本（輸入） |
|---|---|---|
| 為替 | 円安は追い風。ドル円は2026年1月に一時159円台、年末に向けて緩やかな円高という見通しもある【事実】（見通し） | 円安は仕入れ値を押し上げる【推測】 |
| 需要の裏付け | eBayの公表資料で、カメラ・自動車部品・トレカ・釣り具の伸びを確認できる【事実】 | 海外限定品の需要は個人ブログが中心で、裏付けが弱い【推測】 |
| 規制 | 米国向けは関税の先払い（DDP）が必須で、ルールの変更が続く【事実】 | 電気製品のPSE、無線機器の技適、化粧品などの薬機法、商標【事実】（解説記事）。**販売目的の輸入に個人輸入の免税枠を使うのは違法**【事実】（解説記事） |
| 方針との一致 | 外貨を稼ぐ方針と合う | 顧客は日本人で、方針から外れる |

**判断【推測】**: 輸出を優先する。輸入は、扱うなら「規制のない海外限定の雑貨」に限り、輸出が軌道に乗ってから検討する。

## 3. 「ちょうど良い」を決める基準

| 基準 | 理由 |
|---|---|
| 仕入れ単価 5,000〜30,000円 | 10万円から許可の手数料を引いた約8万円で、3〜10点を回せる。1点の失敗で資金が尽きない |
| 小さく、軽く、壊れにくい | 国際送料と破損のリスクを抑える。一人で梱包できる |
| 検品が手順にできる | 状態の見極めを誤ると返品・評価の低下につながる。AIが手順書を作り、人間が確認する形にしやすい |
| 偽物が少ない | 偽物を売るとアカウントの停止につながる |
| 規制がない | 電池・刃物・酒・動植物などを避ける |
| 価格差を調べられる | eBayの落札済み一覧と、国内の店舗・オークションの相場を比べられる |
| 国内の仕入れ先が多い | ハードオフ、ブックオフ、ヤフオク、地方のリサイクル店など |

### 4.3 各案の要点

**1位: 中古リール**
- 需要が伸びていて、eBay自身が成長を公表している【事実】。
- 小さく、割れにくい。梱包が簡単で、送料も抑えられる【推測】。
- 検品は「回転のなめらかさ、異音、ドラグ、ベールの動き、傷」で、手順にしやすい【推測】。
- シマノ・ダイワの現行・旧型の型番が多く、型番で相場を調べやすい【推測】。
- 注意: 大手の釣具店（タックルベリー）が同じ市場に入ってきた【事実】。高級機は偽物の報告がある可能性【未確認】。米国の関税率は未確認【未確認】。

**2位: 中古レンズ**
- 需要は最大級で、豪州など米国以外にも売れる【事実】。
- ボディより小さく、可動部が少ないので、フィルムカメラ本体より検品が易しい【推測】。
- 注意: カビ・曇り・バルサム切れの見落としが返品の主な原因になる【推測】。ライトで透かす検品を人間が覚える必要がある。人気の分野なので、国内の仕入れ値も上がっている可能性がある【未確認】。

**3位: レトロゲームのソフト（練習向け）**
- 起動の確認だけで検品でき、1本数百〜数千円で仕入れられる。失敗しても損が小さい【推測】。
- 注意: 単価が低いため、国際送料と手数料の割合が大きい。**まとめ売り（数本セット）**にしないと利益が残りにくい【推測】。人気作の海賊版・リプロ品が混ざる【推測】。

**避ける商材の理由【推測】**
- ポケモンカードの高額品: 偽物が多く、鑑定済み（PSA）でないと高く売れない。値動きが大きく、発売直後に下がる。新品の箱は購入制限があり、仕入れが難しい。
- 時計・ブランド品: 取引額は大きいが、真贋の判定が難しい。
- 包丁: 英国は刃渡り約20cm超を直送できないなど、国ごとに規制がある（[budget-100k-business-ideas.md](budget-100k-business-ideas.md) §2）。
- 工芸品: 割れ物で、梱包と破損の補償が重い。
- 酒類（日本のウイスキー等）: eBayでは原則出品できない【未確認】。

## 5. 輸入の候補（参考）

扱うなら次の条件を満たすものに限る【推測】。

- 規制がない（電気・無線・化粧品・食品・医薬品を除く）
- 国内に正規の販売店がない、または国内価格が海外の2倍近い
- 商標・並行輸入の問題がない

具体的な品目は、今回の調査では信頼できる資料が見つからなかった【未確認】。なお、メルカリでは2025年10月の規約改定で営利目的の出品の扱いが変わったとする解説がある【未確認】（[libecity](https://library.libecity.com/articles/01KVQP0CRANHRS3ZYKB4547B5C)）。国内で売る場合は、メルカリShopsやAmazonの規約を確認する必要がある。

## 6. 次にやること：価格差の実測

利益率はどの商材も未確認のため、仕入れる前に次の手順で確かめる【推測】。

1. 候補ごとに20品目（型番・タイトル）を選ぶ。
2. eBayの**落札済み（Sold）**の価格を、過去90日で調べる（出品中の価格ではなく、売れた価格）。
3. 国内の仕入れ値を調べる（ハードオフ・ヤフオクの落札価格など）。
4. 次の式で1点あたりの利益を出す。

```
利益 = 売値（ドル）× 為替（円/ドル）
     − eBayの手数料（売値 × 料率）
     − 国際送料
     − 関税（米国向けはセラーの先払い）
     − 両替・送金の手数料
     − 仕入れ値 − 梱包材
```

5. 「利益が仕入れ値の30%以上」かつ「90日で3件以上売れている」品目を残す（基準は【仮定】で、実測後に直す）。
6. 残った品目が多い商材を選び、最初は2〜3点だけ仕入れる。

調べる作業（2〜4、式の計算）はAIが担える。ただし、eBayのSoldの一覧はログインが必要な場合があり、人間がブラウザで確認する必要がある可能性がある【未確認】。

## 8. 必要な人間の判断と承認

- せどりを進めるかどうか（ローカライズ事業との優先順位）
- 仕入れ・検品・撮影・梱包・発送を担当できるか
- 古物商の許可の申請と、手数料19,000円の支出
- eBayのアカウントの作成と出品（公開・契約に当たる）
- 在庫の購入
