## 3. 中古カメラ・レンズのeBay輸出

### 開業の費用（10万円の内訳）

| 項目 | 金額 | 区分 |
|---|---|---|
| 古物商の許可（手数料＋書類） | 約21,000円 | 【事実】（[freee](https://www.freee.co.jp/kb/kb-license/curio_dealer_license/)） |
| 梱包材・清掃道具・撮影用品 | 約6,000円 | 【仮定】 |
| **在庫に回せる金額** | **約73,000円**（1台25,000円なら約3台） | 【推測】 |

### 1台あたりの収支（例: eBayで300ドル（送料込み）で売れるフィルムカメラ）

| 項目 | 米国向け | 英国・豪州向け | 区分 | 根拠 |
|---|---|---|---|---|
| 販売価格 | 300ドル ＝ 46,500円 | 同じ | 【仮定】 | 人気のフィルムカメラで出品価格230〜870ドルの例【事実】（[eBay](https://www.ebay.com/b/Olympus-mju-II-35-mm-Film-Cameras/15230/bn_115134551)）。実際に売れた価格は未確認 |
| eBayの手数料（約15%） | −7,000円 | −7,000円 | 【未確認】 | カメラは9.35〜13.6%と資料で食い違う。海外販売の手数料を足して15%と置いた（[ZIK Analytics](https://www.zikanalytics.com/ebay-fee-calculator/)） |
| 両替の手数料（2%） | −900円 | −900円 | 【未確認】 | |
| 送料（FedEx・約1kg） | −5,000円 | −5,000円 | 【仮定】 | 公式の料金表は未確認 |
| 関税（約12%、DDPで先払い） | −5,600円 | 0円（輸入時の税は購入者側）【未確認】 | 【未確認】 | 米国は約10〜12.5%とする資料がある |
| **仕入れ前の手取り** | **約28,000円** | **約33,600円** | 【推測】 | |
| 仕入れ（国内送料込み） | −25,000円 | −25,000円 | 【仮定】 | |
| **1台の利益** | **約3,000円（6%）** | **約8,600円（18%）** | 【推測】 | |
| 作業時間 | 約2〜3時間（仕入れ、検品、清掃、撮影、出品、梱包） | 同じ | 【仮定】 | |

- **利益は仕入れ値でほぼ決まる。** 300ドルで売れる商品なら、米国向けで赤字にならない仕入れの上限は約28,000円。1台8,000円の利益を出すには、仕入れを約20,000円（eBayの販売価格の約43%）に抑える必要がある【推測】。
- 国内と海外の価格差が近年どれだけ残っているかは確認できていない。eBayで実際に売れた価格と、メルカリ・ヤフオクの価格を数十件比べるのが最初の作業になる【未確認】。
- 米国向けは関税の分だけ利益が薄い。米国以外の国を主な販売先にするか、関税の分を価格に乗せる【推測】。

### 月ごとの台数と利益

| シナリオ | 月の販売台数 | 1台の利益 | 月の利益 | 必要な在庫資金 | 月の作業時間 |
|---|---|---|---|---|---|
| 保守 | 2台 | 3,000円 | 約6,000円 | 約5万円 | 6時間 |
| 標準 | 3台 | 6,000円 | 約18,000円 | 約7.5万円（予算内） | 8時間 |
| 好調 | 15台 | 7,000円 | 約105,000円 | 約40万円 | 40時間 |

- 予算の10万円では、在庫は3台前後が上限【推測】。月10万円の利益に届くには、利益を在庫に回して資金を約40万円まで増やす必要がある。標準シナリオのペースでは1年以上かかる【推測】。
- 売れ残りのリスク: 在庫が売れないと、資金が止まって次の仕入れができない。

### 初期費用と期間

- **初売上まで**: 古物商の許可に約40日かかるため、早くて開始から約50〜60日後【推測】。自分の不用品を先に売れば早められるが、許可が必要かどうかは確認が必要【未確認】。

## 4. 2つの比較

| | ローカライズの品質チェック | 中古カメラのeBay輸出 |
|---|---|---|
| 1件・1台の利益 | 約6,900円 | 約3,000〜8,600円（仕入れ値と販売先しだい） |
| 利益率 | 約95% | 約6〜18% |
| 時給換算 | 約3,500〜7,000円 | 約1,000〜4,000円 |
| 標準シナリオの月の利益 | 約35,000円 | 約18,000円 |
| 月10万円に必要な量 | 月15件・25時間 | 月15台・40時間＋在庫資金40万円 |
| 初期費用 | 0〜1万円 | 約10万円（許可＋在庫） |
| 初売上まで | 2〜6週間 | 50〜60日 |
| 何が増えると伸びるか | 評価の数と単価 | 在庫資金と仕入れの目利き |
| 最大のリスク | 注文が来ない | 仕入れ値が高く利益が出ない／売れ残る |

**数字の上では、ローカライズのほうが利益率も時給も高い【推測】。** 中古カメラは利益が薄く、資金も時間もかかる。ただし、仕入れの目利きができれば利益は大きく変わる。その点で、カメラが好きかどうかが効いてくる事業だと言える。

## 5. 両方やる場合の進め方（案）【推測】

予算と時間がぶつからないよう、時期をずらす。

| 時期 | ローカライズ | 中古カメラ |
|---|---|---|
| 1か月目 | Fiverrに出品し、最初の評価を集める（低価格の入門メニュー） | 古物商の許可を申請する（19,000円）。eBayで売れた価格と国内の仕入れ値を調べる |
| 2か月目 | 評価が集まれば価格を上げる | 許可が下りたら、調査で利益が出ると分かった機種を2〜3台仕入れて出品する |
| 3か月目 | 標準シナリオ（月5件）を目指す | 実績を見て、続けるか、機種を絞るか、やめるかを決める |

3か月目の時点の目安（標準シナリオ）は、ローカライズ約35,000円＋カメラ約18,000円で**月約5万円**【推測】。中期目標の月1万円は超え、長期目標の月10万円の半分にあたる。

## 6. 試算の精度を上げるために確認すること

| 項目 | 影響 | 確認方法 |
|---|---|---|
| eBayで実際に売れた価格と、国内の仕入れ値の差 | カメラの利益をほぼ決める | eBayの「Sold items」とメルカリ・ヤフオクの落札価格を機種ごとに比べる |
| eBayのカメラの手数料率と海外販売の手数料 | 1台あたり数千円の差になる | eBay公式の手数料ページ |
| FedExの送料と、DDPの手数料 | 1台あたり数千円の差になる | eLogi・CPaSSの料金表 |
| 米国の現在の関税率 | 米国向けの利益を左右する | CBP・USTRの公式情報 |
| Fiverrで新規の出品者が最初の注文を得るまでの期間 | ローカライズの立ち上がりを左右する | 出品して実測する |
