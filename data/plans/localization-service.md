# サービス設計：Steam・App Storeのストアページの日本語チェック

- 作成日: 2026-10-29
- タスク: T0005（前提: T0004 [localization-validation.md](../research/localization-validation.md)）
- 表記: **【事実】** 出典で確認済み / **【推測】** 分析・仮説 / **【未確認】** 裏付けなし / **【仮定】** 計算のために置いた数字
- 位置づけ: 出品ページの**設計案**。Fiverrへの出品（公開・契約）は人間の承認を得てから行う

## 0. 要約

| 項目 | 決定案 |
|---|---|
| 商品 | AI翻訳や機械翻訳で作った**既存の日本語ストアページ**を、日本語ネイティブが英語の原文と照らしてチェックする。修正版と、英語で書いた修正理由のレポートを納品する |
| パッケージ（通常価格） | Basic **25ドル** / Standard **60ドル** / Premium **120ドル** |
| 入門価格（評価が10件たまるまで） | Basic **20ドル** / Standard **50ドル** / Premium **100ドル**。クーポンは使わない（値引き分は出品者の取り分から引かれるため。§1.3） |
| 対象 | Steam: 短い説明、ゲームの詳細（About This Game）。App Store: 名前、サブタイトル、プロモーションテキスト、説明、キーワード、新機能 |
| 対象外 | ゲーム本文・UI・音声、ゼロからの翻訳、画像の編集、法務文書、**Steamのタグ**（Steamが自動で翻訳する。§2.3） |
| 品質の約束 | 範囲内の文章は人間が100%読む。重大（Critical）と大（Major）の問題を残さない。各欄を文字数の上限に収める。すべての修正に英語の理由を付ける |
| 分担 | AIが「指摘の候補・修正の下書き・英語レポートの下書き・文字数の機械チェック」を作り、人間が「全文を読む・指摘を採否する・最終的な文を決める・納品前に通して読む」を担う |
| 1件の利益（通常価格） | Basic 約2,800円 / Standard 約6,900円 / Premium 約14,000円。時給はどれも約2,800〜3,100円【推測】 |

## 1. パッケージ

### 1.1 3つのパッケージ

量は**英語の原文の語数**で区切る。海外の開発者が数えやすく、競合も語数か文字数で区切っているため（[localization-validation.md §5の集計](../research/localization-validation.md)）【事実】。日本語の文字数の目安は英語の約1.5〜2倍とみる【推測】。

| | **Basic** | **Standard**（主力） | **Premium** |
|---|---|---|---|
| 想定する用途 | 短い欄だけ直したい。まず品質を試したい | ストアページの文章をまるごと直したい | 発売前に、画像や動画の日本語まで含めて仕上げたい |
| 対象の欄 | Steam: ゲーム名・短い説明 ／ App Store: 名前・サブタイトル・プロモーションテキスト・キーワード | Basicの欄 ＋ Steam: ゲームの詳細（About This Game）／ App Store: 説明・新機能 | Standardの欄 ＋ スクリーンショット・カプセル画像の中の文字（10枚まで）＋ トレーラーの字幕（3分まで） |
| 量の上限（英語の原文） | **150語まで** | **800語まで** | **1,500語まで**（画像・字幕の文字は別枠） |
| 納品物 | 修正版の日本語 ／ 英語の簡易レポート（修正箇所と理由） ／ 各欄の文字数 | Basicの内容 ＋ **重要度つきの英語レポート** ＋ **用語集（20語まで）** | Standardの内容 ＋ 画像・字幕の表示の指摘（はみ出し・改行・禁則・フォント）。画像には**指摘を書き込んだスクリーンショット**を付ける |
| 納期 | 2日 | 3日 | 5日 |
| 修正回数 | 1回 | 2回 | 3回 |
| **通常価格** | **25ドル** | **60ドル** | **120ドル** |
| **入門価格** | **20ドル** | **50ドル** | **100ドル** |
| 購入者の支払い（通常価格）※ | 約29.9ドル | 約66.8ドル | 約130.1ドル |
| 想定の作業時間【仮定】 | 1.0時間 | 2.5時間 | 4.5時間 |

※ 購入者はサービス料5.5%と、200ドル未満の注文で3.5ドルを別に払う【事実】（[Fiverr: Paying for orders](https://help.fiverr.com/hc/en-us/articles/360050216133-Paying-for-orders-extras-or-custom-offers)。別のページでは「100ドル未満で3ドル」とあり食い違う）。

**「修正回数」の決まり**
- 1回の修正とは、購入者の意見を受けて、納品した範囲の中で直すこと。
- 納品後に**購入者が原文を変えたり、文章を足したりした場合は修正に含めない**。追加の注文とする。
- こちらの誤り（誤訳・見落とし）を直すときは、回数に数えない。

### 1.2 追加オプション（Extras）

| オプション | 価格 | 内容 |
|---|---|---|
| 追加の語数 | 200語ごとに10ドル | 上限を超えた分 |
| 特急（24時間で納品） | Basic +10ドル / Standard +20ドル / Premium +40ドル | 作業時間は変わらない。予定が空いているときだけ受ける |
| 追加の画像 | 1枚3ドル | Premiumの10枚を超えた分 |
| 追加の用語 | 20語ごとに5ドル | 用語集の追加 |
| 2つ目のストア | Standard相当を40ドル | SteamとApp Storeの両方に同じゲームを出している場合。内容の重なりが大きい【推測】 |

- 特急は時給が上がるのではなく、予定を優先する対価。週の作業時間に余裕がないときは出品画面で止める【推測】。

### 1.3 入門価格の考え方

| 案 | 内容 | 評価 |
|---|---|---|
| A. 5ドルまで下げる | 競合の入門価格（5ドルが13件）に合わせる | **採らない**。評価が数百〜千件超の出品者と同じ土俵で負ける。購入者は5ドルの出品でも手数料込みで約8.8ドルを払うため、価格差は見た目ほど大きくない【推測】 |
| B. 少し下げた入門価格から始める | Basic 20ドル。評価10件で25ドルへ上げる | **採用**。購入者の支払いは約24.6ドルで、レビュー専門の競合（#8の50ドル）より安い【推測】 |
| C. クーポンで値引き | 出品価格は25ドルのまま | 採らない。値引き分は出品者の取り分から引かれる【事実】（[Fiverr: Growth Tools for Seller Plus](https://help.fiverr.com/hc/en-us/articles/5244747923985-Growth-Tools-for-Seller-Plus)） |
| D. 最初から25ドル | 入門価格を設けない | 次点。最初の注文が来るまでの期間が分からず【未確認】、少しでも下げて早く評価を集める方を優先する |

**値上げの条件（案）**: ①評価が10件たまる、または②出品から8週間たつ、のどちらか早い方で通常価格にする。評価の平均が4.8を下回る場合は、値上げより品質の見直しを先にする【推測】。

## 2. 対応範囲

### 2.1 対象

| ストア | 欄 | 上限 | 対象のパッケージ | 区分・出典 |
|---|---|---|---|---|
| Steam | ゲーム名（日本語の名前がある場合） | - | Basic〜 | - |
| Steam | 短い説明（Short description） | 公式は「数百文字」。編集画面のカウンターで**300文字**とする第三者の情報あり | Basic〜 | 【事実】（[Steamworks: Description](https://partner.steamgames.com/doc/store/page/description)）／300文字は【未確認】（[Steam Page Analyzer](https://www.steampageanalyzer.com/blog/steam-short-description-guide)） |
| Steam | ゲームの詳細（About This Game） | 上限は確認できず | Standard〜 | 【未確認】 |
| Steam | 説明の中の対応言語や機能の記述と、言語の対応表（インターフェース・音声・字幕）の食い違い | - | Standard〜 | 指摘のみ。設定の変更は開発者が行う |
| App Store | 名前 | 30文字 | Basic〜 | 【事実】（[Apple: Creating Your Product Page](https://developer.apple.com/app-store/product-page/) / [App Review Guidelines](https://developer.apple.com/app-store/review/guidelines/)） |
| App Store | サブタイトル | 30文字 | Basic〜 | 【事実】（[App Store Connect: App information](https://developer.apple.com/help/app-store-connect/reference/app-information/)） |
| App Store | プロモーションテキスト | 170文字 | Basic〜 | 【事実】（[Apple: Creating Your Product Page](https://developer.apple.com/app-store/product-page/)） |
| App Store | キーワード | Appleは「100文字」。第三者は「100**バイト**」とし、日本語は少なく入る可能性 | Basic〜 | 【事実】100文字（同上）／バイトの扱いは【未確認】 |
| App Store | 説明 | 4,000文字 | Standard〜 | 【未確認】（第三者の情報のみ。[AppLaunchFlow](https://www.applaunchflow.com/blog/app-store-metadata-character-limits-2026)） |
| App Store | 新機能（What's New） | - | Standard〜 | 【未確認】 |
| 共通 | スクリーンショット・カプセル画像の中の文字、トレーラーの字幕 | - | Premium | 指摘と修正案のみ。画像や動画の編集はしない |

- **App Storeの日本語の文字の数え方（全角1文字を1と数えるか）は確認できていない【未確認】。** 納品物では、文字数と合わせて「App Store Connectで入力して上限内か確認してください」と案内する。

### 2.2 対象外

| 対象外 | 理由 | 代わりの案内 |
|---|---|---|
| ゲーム本文・UI・アイテム名・チュートリアル | 量が多く、文脈の確認にビルドが必要。品質を約束できない | 将来の別メニュー（§8） |
| 音声・吹き替え・ボイスの台本 | 専門外 | 断る |
| **日本語の文章がない場合の新規の翻訳** | この商品は「既存の日本語のチェック」。ゼロからの翻訳は時間が2〜3倍かかる【推測】 | AI翻訳を自分で作ってから注文してもらうか、カスタムオファーで個別に見積もる |
| 画像・動画の編集、フォントの差し替え | 制作の作業になる | 指摘と修正案の文字だけを渡す |
| 利用規約・プライバシーポリシー・EULA | 法的な責任が生じる | 断る |
| 広告表現の適法性の判断（景品表示法など） | 法的な判断になる | 明らかに誇大と思われる表現は「要確認」として指摘するだけ |
| ASOの順位・売上の保証、キーワードの調査 | 結果を約束できない | キーワード欄は「日本語として自然か・意味が合っているか」だけを見る |
| **Steamのタグ** | ゲームに付けたタグはSteamが自動で各言語に翻訳して表示する。開発者が日本語を用意する必要がない【事実】（[Steamworks: Steam Tags](https://partner.steamgames.com/doc/store/tags)） | 対象外と出品ページに書く |
| Steamworks・App Store Connectへのログインと入力の代行 | アカウントの権限を預かるリスク | 修正版を渡し、入力は開発者が行う |
| 英語以外の原文（中国語・韓国語など） | 原文と照合できない | 断る |
| Google Playなど他のストア | 最初は絞る | 問い合わせが多ければ追加を検討（CEOが判断） |

### 2.3 CEOへの報告（タスクの例との違い）

- タスクの手順3は「タグは対象」を例に挙げていた。しかし**Steamのタグは自動で翻訳される**ため、翻訳のチェックの対象にならない【事実】（上記）。代わりに**App Storeのキーワード欄**を対象に入れた。方針の判断が必要なら見直してほしい。

## 3. 品質基準

### 3.1 問題の種類

| # | 種類 | チェックすること | 例 |
|---|---|---|---|
| Q1 | **誤訳**（正確さ） | 原文と意味が違う、抜けている、足されている。数字、対応機種、対応言語、価格、発売日、プレイ人数が原文と合っているか | 「Co-op for up to 4 players」→「4人以上で協力プレイ」 |
| Q2 | **不自然な表現**（流暢さ） | 直訳調、助詞の誤り、語順、カタカナ語の多用、英語の慣用句の直訳、敬語のちぐはぐ | 「あなたはあなたの運命を選ぶことができます」 |
| Q3 | **文字数の上限** | 各欄が上限に収まっているか（§2.1）。検索結果や一覧で切れて見える位置に大事な語があるか | サブタイトルが31文字 |
| Q4 | **表記ゆれ**（一貫性） | 用語・固有名詞・キャラクター名、長音（サーバー／サーバ）、全角・半角の英数字、句読点（、。と，．の混在）、かっこ（「」『』）、「〜」の使い方。ゲーム内の訳語が提供されていればそれに合わせる | 「ダンジョン」と「迷宮」が混在 |
| Q5 | **日本のストアの慣習**（ロケール） | 文体の統一（です・ます調か、体言止めか）、見出しと箇条書きの記号（■・【】など）、日付と数字の書き方（2026年10月29日）、日本で通じるジャンル名（ローグライク、メトロイドヴァニアなど）、日本の読者に伝わらない比喩・文化の言及 | 「Thanksgiving Sale」をそのまま訳す |
| Q6 | **表示**（Premiumのみ） | はみ出し、不自然な改行、禁則（行頭の「。」など）、文字化け・豆腐（□）、**中国語のフォントで日本語を表示している**（字形の違い）、半角カナ | 「直」「骨」の字形が中国語のもの |

- Q5の「日本のストアでよく使われる書き方」は経験則にもとづく【推測】。統計で確かめたものではない。

### 3.2 重要度

| 重要度 | 定義 | 納品時の扱い |
|---|---|---|
| **Critical（重大）** | 購入の判断を誤らせる、または不快・不適切な表現。例: 対応言語・機能・価格の誤り、差別的な表現 | **ゼロにする** |
| **Major（大）** | 意味が分からない、または日本人が読むと一目で機械翻訳と分かる。文字数の上限超え | **ゼロにする** |
| **Minor（小）** | 意味は伝わるが、表記ゆれ・文体の乱れ・少し不自然な言い回し | 原則すべて直す |
| **Preference（好み）** | 誤りではないが、より良い言い方がある | 修正案として示し、採否は購入者が決める（レポートに「任意」と書く） |

- 重要度の付け方は、翻訳品質の評価の枠組み（MQMなど）の考え方を参考にした簡易版【推測】。

### 3.3 納品の条件（品質の約束）

納品する前に、次をすべて満たす。

1. 範囲内の日本語を、**人間（日本語ネイティブ）が原文と照らして100%読んだ**
2. 納品する文にCritical・Majorの問題が残っていない
3. すべての欄が上限の文字数に収まっている（数え方が【未確認】の欄は注記を付ける）
4. すべての修正に、英語の理由（何が問題で、なぜこう直したか）が付いている
5. 人間が、修正後の文章を**日本の購入者の目で通して読んだ**（原文を見ずに）
6. AIの出力をそのまま納品していない（[Fiverr: Using AI on Fiverr](https://help.fiverr.com/hc/en-us/articles/34998793899665-Using-AI-on-Fiverr-Guidelines-for-freelancers-and-clients) の条件）【事実】

**約束しないこと**: 売上・ダウンロード数・検索順位、ストアの審査の通過、ゲーム本編の訳との一致（本編の訳語が渡されていない場合）。

## 4. 作業の流れとAI・人間の分担

| # | 工程 | 担当 | 内容 | 時間の目安（Standard）【仮定】 |
|---|---|---|---|---|
| 1 | 受付 | **人間** | 範囲・欄・語数の確認。原文（英語）と日本語、ストアのURL、用語の希望を受け取る。範囲外ならカスタムオファーか断る | 15分 |
| 2 | 下準備 | AI（仕組み） | 原文と日本語を欄ごと・文ごとに対応づける。文字数を数える。表記ゆれ（長音・全角半角・句読点）を機械で拾う | 5分（実行と確認） |
| 3 | 指摘の候補 | AI | 原文と照らして、Q1〜Q5の候補を挙げ、重要度の案と修正の下書きを作る | （2の実行に含む） |
| 4 | **全文の確認** | **人間** | 日本語を**全文**、原文と照らして読む。AIの候補を1件ずつ採るか捨てるか決め、AIが見落とした問題を足す。最終的な文を決める | 75分 |
| 5 | **通し読み** | **人間** | 修正後の日本語だけを、日本の購入者の目で読む。文体・流れ・文字数を最終確認 | 15分 |
| 6 | レポートの下書き | AI | 人間が決めた修正をもとに、英語の理由を書く。用語集を表にまとめる | 5分（実行） |
| 7 | **レポートの確認** | **人間** | 英語の説明が修正と合っているか、誤った説明がないかを確認 | 15分 |
| 8 | 納品と修正の対応 | **人間** | 納品。修正の依頼に対応する（平均の時間を含める） | 20分 |
| | 合計 | | | **約2.5時間** |

**分担の原則**
- AIは「候補を出す」まで。**採るか捨てるか、最後の文を決めるのは必ず人間**。
- 文字数・表記ゆれのような機械的なチェックは、AIの判断に頼らず仕組み（スクリプト）で数える【推測】。
- 人間の最終確認者は日本語ネイティブとする。**誰が担当し、月に何時間使えるかは未定【未確認】**。

**AIの利用の開示（Fiverrの条件への対応）**
- 出品ページに「AIを補助に使い、日本語ネイティブが全文を確認・修正します」と書く。「100%手作業」とは書かない【事実】に基づく方針（[localization-validation.md §3](../research/localization-validation.md)）。
- 「AI不可」と言われた注文: 最初は**断る**案とする。受ける場合は工程2・3・6を人間が行い、時間が約1.5倍になる【推測】ため+50%の価格とする。どちらにするかは人間の承認が必要。
- 購入者の未公開の文章をAIに入れる。使うAIツールが**入力を学習に使わない設定か**を確認してから始める【未確認】。

## 5. 1件あたりの収支

### 5.1 前提

| 項目 | 値 | 区分・出典 |
|---|---|---|
| 為替 | 1ドル=155円 | 【仮定】（[profit-estimate.md](../reports/profit-estimate.md)と同じ） |
| Fiverrの手数料 | 注文額の20%（手取り80%） | 【事実】（[Fiverr: Growth Tools for Seller Plus](https://help.fiverr.com/hc/en-us/articles/5244747923985-Growth-Tools-for-Seller-Plus)） |
| 円への換算 | Payoneerで手取りの最大2%を上乗せ | 【事実】料率（[Payoneer: 為替レート](https://www.payoneer.com/ja/resources/how-to-use-payoneer/everything-you-need-to-know-about-conversion-rates/)）。日本在住者が使えるかは【未確認】 |
| 引き出しの固定の手数料 | 1回1〜3ドル。月1回・月5件と置き、多めに**1件0.6ドル**を引く | 【事実】料率（[Fiverr: Withdrawing your earnings](https://help.fiverr.com/hc/en-us/articles/360010530058-Withdrawing-your-earnings-managing-payout-methods)）／配分は【仮定】 |
| AIの利用料 | Basic 100円 / Standard 300円 / Premium 500円（画像を読むため） | 【仮定】 |
| 税 | 消費税は免税事業者のうちはかからない。所得税・住民税は含めない | 【推測】（[localization-validation.md §4](../research/localization-validation.md)） |

### 5.2 計算

計算式: 価格 ×0.8（Fiverr）×0.98（換算）−0.6ドル（引き出し）→ ×155円 − AIの利用料
